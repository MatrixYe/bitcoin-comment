## 1. 基础模块
功能：大数运算、序列化、编码、哈希、签名/验证
源文件：
- uint256.h - 256 位整数
- bignum.h - 大数运算
- util.h/util.cpp - 工具函数
- serialize.h - 序列化框架
- base58.h - Base58 编码
- sha.h/sha.cpp - 哈希算法
- key.h - 密钥管理
## 2. 核心业务模块
功能：交易、区块、区块链、脚本、挖矿、市场
源文件：
- main.h/main.cpp - 核心数据结构与业务逻辑
- script.h/script.cpp - 脚本系统（交易验证核心）
- market.h/market.cpp - 市场功能（实验性）
## 3. 通讯模块
功能：P2P 网络、节点发现
源文件：
- net.h/net.cpp - P2P 网络通信
- irc.h/irc.cpp - IRC 节点发现
## 4. 数据库模块
功能：数据持久化
源文件：
- db.h/db.cpp - Berkeley DB 封装
## 5. UI 模块
功能：用户界面
源文件：
- ui.h/ui.cpp - UI 实现
- uibase.h/uibase.cpp - UI 基础框架
